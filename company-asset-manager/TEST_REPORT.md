## 公网入口

原域名 `tencent.geneecho.top` 的 TLS 请求在网络路径上被重置。服务器抓包确认它收到 ClientHello 并正常发回 TLS 数据，之后收到异常重置包。该问题通过配置带有效公网证书的 IP 入口解决，不依赖原域名、不使用代理、不关闭证书校验。

初次交付使用 IP 入口。本次按用户要求修复域名：Cloudflare 上的 `tencent` A 记录保留服务器 IP 并启用代理，添加仅匹配该域名 HTTPS 请求的 Origin Rule，回源端口为 8443。腾讯云新增 TCP 8443 入站规则；Caddy 使用 HTTPS / HTTP/1.1 回源。另添加仅匹配 `http://tencent.geneecho.top/*` 的 301 Redirect Rule，跳转 HTTPS 并保留查询参数。其他域名 DNS 记录保持不变，Full 加密模式保持不变。

正式入口为 `https://tencent.geneecho.top/asset-manager/`，备用 IP 入口仍可使用。域名根路径仍为原有 Web Test Agent，资产管理使用 `/asset-manager/`。HTTP 请求保留原 80 端口路径及 HTTPS 跳转，以支持域名证书的自动 HTTP-01 验证。
